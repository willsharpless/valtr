temporal logic -> decomposed Value graph

        

          

            This tool translates a temporal logic specification into a decomposed Value graph, which allows one to solve the optimal Value & policy for the given spec. 
            


            The DVG is generated by first manipulating the temporal logic tree associated with the formula to make it amenable to Value decomposition algebra. Then, the Value is defined over this structure and the rules applied, yielding a graph of max, min, negation, atomic Bellman Values (avoid, reach-avoid, reach-avoid-loop) and the predicates. This process is equivalent to transforming the overall task Value into a coupled set of Values, each with a known Bellman equation.
            


            To write temporal logic, string together operators to specify complex tasks (or ask your favorite LLM), using the following symbols:
          

          
Ffinally/eventually ie. to reach a state

          
Gglobally/always ie. to maintain a state (and avoid leaving it)

          
Uuntil

          
&&and

          
||or

          
!not
